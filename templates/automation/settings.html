Información para responder consultas

Separá el contexto general de la empresa de las respuestas puntuales. Así el agente entiende el marco, pero sólo responde consultas concretas con datos aprobados y encontrados por el buscador.

1

Contexto general

Es el background estable: quiénes son, qué venden, tono y límites. Se agrega siempre, como una brújula.

2

Datos puntuales

Son tarjetas cortas de FAQ: experiencia, productos, medidas, entregas o qué información pedirle al cliente. No lee catálogos PDF automáticamente.

3

El buscador elige hasta 3

Cuando llega una consulta, se buscan las tarjetas más parecidas. Si no hay algo claro, o la consulta pide precio/reunión/criterio comercial, va a una persona.

Agregar dato puntual

Cada tarjeta debería responder una sola duda. El buscador compara la consulta del cliente con estas tarjetas y elige pocas.

{% include "includes/field.html" with field=knowledge_form.title %} {% include "includes/field.html" with field=knowledge_form.category %} {% include "includes/field.html" with field=knowledge_form.text %} {% include "includes/field.html" with field=knowledge_form.source_notes %}
Antes de guardar:
No cargues precios, promesas especiales, datos dudosos ni instrucciones privadas para el cliente. Si algo requiere criterio comercial, conviene que lo responda una persona.
Después vas a poder aprobarlo para que el agente lo use.

Qué conviene escribir

  • Respuestas cortas a preguntas frecuentes.
  • Datos permanentes de la empresa.
  • Productos o aplicaciones que sí ofrecés.
  • Qué dato pedirle al cliente cuando falta información.

Qué conviene evitar

  • Precios o cotizaciones.
  • Promesas que cambian según el caso.
  • Información que “creés” que es cierta pero no confirmaste.
  • Textos larguísimos copiados de un catálogo.
